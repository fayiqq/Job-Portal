# 💼 Job Portal Web Application

A full-stack **Job Portal Web Application** built using the **MERN Stack** that allows recruiters to post jobs and candidates to search and apply for jobs online. The platform provides secure authentication, job management, and application tracking through a modern and responsive UI.

---

## 🚀 Features

- JWT-based Authentication (Login / Signup)  
- Role-Based Access (Candidate / Recruiter / Admin)  
- Job Posting Management (Create, Read, Update, Delete)  
- Job Search and Filtering  
- Job Application System  
- Cloudinary File Upload (Profile Images / Resumes)  
- Fully Responsive Design
